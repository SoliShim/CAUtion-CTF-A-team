CAUtion CTF 맥미니 자동 실행 안내

맥미니가 재시동된 뒤 로그인하면 Docker 문제 서버 5개와 Cloudflare 무료 임시 터널 5개가 자동으로 실행됩니다. 공유 링크는 매번 자동 실행 전용 폴더의 ctf_tunnel_links.html에 갱신됩니다.

현재 방식: 포트포워딩 없이 맥미니 내부의 Docker 서버를 Cloudflare trycloudflare.com 무료 임시 터널로 외부에 공개합니다.

비용: 이 구성은 유료 클라우드 리소스를 만들지 않습니다.

가장 먼저 알아둘 것

sh 파일을 실행한다는 말은 터미널 앱에 ./scripts/파일이름.sh 같은 명령어를 입력하고 Enter를 누른다는 뜻입니다.

아래 명령어들은 한 줄씩 복사해서 터미널에 붙여넣고 Enter를 누르면 됩니다.

비밀번호를 물어보는 창이나 입력란이 나오면 맥 로그인 비밀번호를 입력하세요. 터미널에서는 비밀번호를 입력해도 화면에 글자가 보이지 않을 수 있지만 정상입니다.

터미널 여는 법

  1. 키보드에서 Command + Space를 누릅니다.
  2. Terminal 또는 터미널을 입력합니다.
  3. 터미널 앱을 열고, 아래 명령어를 한 줄씩 복사해서 붙여넣습니다.

작업 폴더로 이동

스크립트는 이 프로젝트 폴더 안에서 실행해야 합니다. 터미널을 열고 먼저 아래 명령어를 실행하세요.

cd /Users/sungminshim/Documents/GitHub/CAUtion-CTF-A-team

이 명령어는 “이 CTF 프로젝트 폴더로 이동한다”는 뜻입니다. 이후 명령어는 이 위치에서 실행합니다.

처음 한 번만 자동 실행 설치

맥미니를 재시동했을 때 자동으로 CTF 서버가 켜지게 하려면 아래 명령어를 실행합니다.

./scripts/install_macos_autostart.sh

이 명령어는 현재 문제 파일과 설정을 자동 실행 전용 폴더에 복사하고, macOS 로그인 시 자동으로 서버가 켜지도록 등록합니다.

재부팅 후 링크 확인

맥미니를 재시동한 뒤 로그인하고 1분 정도 기다린 다음, 최신 참가자 링크를 확인합니다.

HTML 파일로 열기:

open ~/.caution-ctf-a-team/ctf_tunnel_links.html

터미널에 링크만 출력하기:

./scripts/show_tunnel_links.sh

나오는 https://...trycloudflare.com 주소 5개를 참가자에게 전달하면 됩니다.

scripts 폴더 파일별 용도

아래 표는 참고용입니다. 평소에는 위의 “상황별로 실행할 명령어”만 보면 됩니다.

파일 용도 언제 실행하나
install_macos_autostart.sh 재부팅 후 자동 실행을 macOS에 설치하고, 현재 문제 파일과 설정을 ~/.caution-ctf-a-team에 복사합니다. 처음 자동 실행을 설정할 때, 플래그나 문제 파일을 바꾼 뒤 자동 실행 전용 폴더에 다시 반영할 때 실행합니다.
show_tunnel_links.sh 현재 실행 중인 Cloudflare 무료 터널 주소 5개를 터미널에 출력합니다. 참가자에게 보낼 최신 링크를 빠르게 확인하고 싶을 때 실행합니다.
stop_free_tunnels.sh 문제 서버와 Cloudflare 터널 컨테이너를 모두 중지합니다. 대회가 끝났거나 서버를 잠시 내려야 할 때 실행합니다.
start_free_tunnels.sh 자동 실행과 별개로 문제 서버 5개와 무료 터널 5개를 즉시 실행합니다. 자동 실행을 기다리지 않고 지금 바로 수동으로 서버를 켜고 싶을 때 실행합니다.
autostart_ctf_tunnels.sh Docker Desktop이 준비될 때까지 기다린 뒤 문제 서버와 터널을 올리고 링크 HTML을 갱신합니다. macOS LaunchAgent가 재부팅 후 자동으로 실행하는 내부용 파일입니다. 보통 직접 실행하지 않습니다.
generate_tunnel_links_html.sh 현재 터널 로그에서 trycloudflare.com 주소를 읽어 ctf_tunnel_links.html 파일을 만듭니다. 자동 실행 또는 수동 시작 스크립트가 내부에서 사용합니다. 링크 HTML만 다시 만들고 싶을 때 직접 실행할 수 있습니다.
uninstall_macos_autostart.sh macOS 재부팅 자동 실행 설정을 제거합니다. 다음 로그인 때 CTF 서버가 자동으로 켜지지 않게 하고 싶을 때만 실행합니다.

정리하면, 평소에는 install_macos_autostart.sh, show_tunnel_links.sh, stop_free_tunnels.sh 정도만 기억하면 됩니다.

플래그 관리

실제 대회 플래그는 저장소의 .env.ctf에 넣은 뒤 ./scripts/install_macos_autostart.sh를 다시 실행해 자동 실행 전용 폴더로 반영합니다. 이 파일은 .gitignore에 포함되어 깃에 올라가지 않습니다.

COMMAND_FLAG=FLAG{...}
SQL_FLAG=FLAG{...}
CSRF_FLAG=FLAG{...}
XSS_FLAG=FLAG{...}
FILE_UPLOAD_FLAG=FLAG{...}

주의할 점

  • trycloudflare.com 임시 링크는 무료이지만, 터널 컨테이너가 새로 만들어지면 주소가 바뀔 수 있습니다.
  • 재부팅 후 Docker Desktop이 완전히 뜨는 데 시간이 걸릴 수 있습니다. 링크 파일이 비어 있으면 1분 정도 기다린 뒤 새로고침하세요.
  • 로그는 ~/.caution-ctf-a-team/logs/autostart.out.log와 ~/.caution-ctf-a-team/logs/autostart.err.log에서 확인할 수 있습니다.
